## 产品文档包

楼响面向豪宅销售团队，帮助团队把真实房源资料和授权素材变成专业内容，再把主动咨询、销售跟进与下一轮内容连接起来。首轮范围是一个客户、一个楼盘、一条内容链路、一个合规咨询入口和内置轻 CRM。

版本 v0.1，2026年10月11日。首个服务对象已经用户确认；其余功能、排期、预算和目标是供业务与技术共同评审的方案，不代表产品已实现、平台权限已取得或业务效果已验证。暂用楼响 HouSignal 为项目名，正式品牌注册与账号另核验。

## 文档和模板

docs 保存可编辑 Markdown 源文件；exports 提供 PRD Word、各文档 Word、完整合订 Word 和文档包 ZIP。Word 中流程图使用文字流程便于无插件阅读，完整 Mermaid 源码保存在 Markdown 中。核心资料收集模板、单条内容交付模板和销售反馈模板位于 examples；它们为空白业务模板，不能当作真实房源或真实线索证明。

## 统一产品规则

- LeadEntry.capability_mode 为 manual_native、approved_native_component 或 owned_form_allowed，默认人工站内承接。
- 事实状态为 unverified、verified、disputed、expired；关键审批针对不可变版本。
- 咨询候选和销售确认后的资格线索分开；CRM从 qualified 起，随后 appointment、visit_completed、opportunity、won/lost/withdrawn。
- 导出不等于发布，真实平台作品回执才进入发布统计；人工登记不等于官方接口验证。
- 来源可信度为 confirmed、self_reported、inferred、unknown，来源不明不强行归因。
- 小艾大叔公开资料仅作为研究启发，未完整观看样本视频或取得字幕，未确认其本人参与或授权。

## 评审后第一步

用[决策登记](docs/12_决策登记与用户访谈.md)落实一个真实客户、一个有营销许可的楼盘、授权素材、事实负责人、销售承接人、可用账号入口和研发预算。随后共同确认 FR 范围、排期和验收。交付使用真实成片、审批、作品回执、获授权咨询及销售反馈证明；模拟数据只用于技术演示。
