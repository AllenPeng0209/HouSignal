# 楼响 HouSignal 正式应用

React + TypeScript + Vite、FastAPI、PostgreSQL、百炼 Qwen、独立持久 Worker。楼管家位于 WORKSPACE 上方，账号、技能库与内容工作台保持当前品牌与视觉。业务记录由后端与数据库保存；浏览器只保存当前项目选择。

工作台是当前项目的默认首页，包含「项目总览 / 效果分析」。总览集中显示项目进展、今日待办、内容效果、销售进展和已有下一步建议；效果分析保留发布回执核验、指标回填和人工采纳。原「效果复盘」不再作为一级导航，既有楼管家引用和页面跳转仍进入效果分析。楼管家继续提供独立对话入口。作品发布后 D7 / D30 与项目累计销售阶段分别标注，缺失指标保留待观察。

## 本地运行

当前工作区的百炼凭证按用户授权复用 LoveLingo，安全保存在根 `.env`；未复制原项目的业务数据库，也未修改其配置。此文件权限为0600，不进入前端、容器镜像或源码包。

应用地址：<http://127.0.0.1:8017/>。本地开发登录使用私有 `.env` 中的 `BOOTSTRAP_EMAIL` 与 `BOOTSTRAP_PASSWORD`，实际凭据不随源码提交。两个种子项目均显示“示例项目”，不代表真实楼盘和客户。新安装的生产环境用独立管理员账号，不载入示例数据。

已安装依赖的工作区可直接执行：

```sh
.venv/bin/python scripts/start_local.py --seed
.venv/bin/python scripts/stop_local.py
```

首次安装可先执行 `uv venv .venv --python 3.12`，再执行 `uv pip install --python .venv/bin/python -r apps/api/requirements.lock`；使用 Node.js ≥22.19.0，执行 `npm ci --prefix apps/agent-runtime` 安装固定版本 Pi Agent Core 1.2.0，再在 `apps/web` 执行 `npm ci && npm run build`。根 `.env.example` 提供配置字段，实际凭证保持私有。该 macOS 启动脚本使用已安装 PostgreSQL 17，独立实例位于 `.runtime/postgres`、端口55432；文件在 `.runtime/storage`。启动不会清空现有数据。

楼管家现在由实际 Pi Agent Core 调度原生 CRM、预约、楼盘、素材及内容/视频制作工具。运行中可补充当前事项或排队后续交代；制作完成后的续接由持久队列等待真实结果后继续。详细方案见 [SECRETARY_AGENT.md](docs/SECRETARY_AGENT.md)，侧车协议见 [Agent Runtime](apps/agent-runtime/README.md)。Docker API/Worker 镜像已包含对应 Node 与固定依赖。

新目录将 `.env.example` 复制为 `.env` 并设为0600；为应用、迁移、Worker分别填写 `postgresql+psycopg://housignal_app:密码@127.0.0.1:55432/housignal`、`housignal_owner`、`housignal_worker` 的数据库URL，密码需URL编码。填写独立的 `SECRET_KEY`（至少32个随机字符）、`PII_ENCRYPTION_KEY`（Fernet格式的Base64编码32字节密钥）及开发登录密码，并填写自己的百炼密钥和工作空间支持的兼容端点。`local_db.py`会按这些配置创建专属角色；私有运行目录与socket目录为0700，日志为0600。首次运行 `--seed` 会使用源码中的三张示意图创建两份示例项目，已有账号时跳过种子导入。

开发前端可在 `apps/web` 执行 `npm run dev`，端口5177，代理 `/api` 到8017。正式构建由 API 的8017同源提供。

## AI响应与性能

常见资料查询使用安全的服务器工具计划，实际查询数据库后一次生成；复杂、歧义或多对象问题保留工具调用。模型输入只投影必要业务字段，完整来源仍进入审计与权限复查。旧对话上下文设6000字符总预算，保留完整当前问题、近期称呼与必要引用。

本地已验证并配置 `DASHSCOPE_CHAT_MODEL=qwen-flash` 用于明确的轻量查询；空值则沿用 `DASHSCOPE_MODEL`。复杂客户分析与文案生成继续使用 `qwen-plus`。先用自己工作空间的授权模型做质量验收，再设置查询模型；不因为快就默认更换文案模型。

本轮验收调用达到原本地聊天每日阈值。当前开发环境设置 `DEVELOPMENT_TOKEN_BUDGET=200000` 供继续试用，所有模型用量仍保留；配置示例默认100000，生产环境仍强制使用原100000阈值，不读取开发覆盖值。该配置不会修改百炼账户真实配额或购买额度。

真实回答由百炼流式返回，经来源与权限检查后写入临时任务预览，再通过同源SSE显示。完成后一次读取最终消息和引用；失败、取消、撤权会清掉预览。原模型输入与HTTP凭证不进入SSE。网络断开可有限轮询恢复，切页面关闭监听，不取消已授权的后台工作。

Worker固定2个聊天槽和2个后台槽，后台识别／生成／成片不会占用聊天槽；每个任务有独立数据库Session和租约。新增开始、尝试、完成及首次可见预览时间，支持区分排队与执行。`first_token_at`是首次经过安全检查的可见预览时间，供应商首token耗时另在适配器 `_timing` 返回，两者不可混用。百分比按0到1正确显示，媒体批次按真实阶段更新。

自动草稿默认2–4个镜头，最多4个，成片总时长仍为15–60秒；超过预算会明确拒绝，不能静默截断。手工编辑保持既有镜头能力。脚本JSON须全部生成并核验后才能成为可编辑版本，生成期间展示实际处理阶段。

性能回执位于 `reports/ai-performance-verification.json`。可用 `PYTHONPATH=apps/api .venv/bin/python scripts/benchmark_ai.py --label check --kind chat --scenario overview` 重测；只对示例项目创建清晰标识的性能对话，会真实调用模型。实测样本不代表供应商未来延迟保证。

## 部署与数据

`compose.yaml` 包含PostgreSQL、迁移、API、Worker和Nginx前端；`docker compose config --quiet`已验证配置；本机Docker守护进程未运行，容器镜像构建尚未实测。API与Worker分进程，原件与成片保存在共享私有持久卷。应用账号不是表所有者、超级用户或BYPASSRLS；Worker仅对队列表有跨组织领取任务权限，其余数据仍绑定当前任务组织。

生产配置需提供独立数据库密码、安全密钥、管理员密码与部署域名 `DEPLOY_ORIGIN`。生产Cookie为Secure，Nginx入口应置于HTTPS终止代理之后。启动后运行管理员初始化命令 `docker compose run --rm api python scripts/bootstrap_owner.py`。该命令不创建示例项目，也不会覆盖已有账号。

本轮未创建阿里云资源、连接正式RDS/OSS、配置公网域名或部署HTTPS。当前文件存储采用私有持久文件卷；阿里云上线可挂载持久卷或继续接OSS适配器。平台发布与指标保持人工正规路径，未接抖音／小红书官方账号接口。关键词文档检索已实现，pgvector语义召回作为后续检索增强。

## 原生内容技能（2026年10月14日）

内容任务由本项目 `app/native_skills.py` 与 `app/content_skills/` 执行。114种方法按文字、公开研究、媒体、项目数据与平台操作分派，保留原产品入口ID后共有119项能力入口。运行配置、模型凭据、账号会话、授权素材、数据库记录和任务产物均由楼响管理。

技能页面按实际依赖显示准备状态，支持选择本项目素材、填写结构化参数并查看持久任务和真实产物。文字模型使用当前已核验事实与项目画像；公开研究保留真实来源、获取时间和指标缺失状态。图片、音视频、文档与图表在项目工具中处理；画像、日历、ROI与复盘查询项目数据库并执行真实计算。平台登录与发布使用项目账号流程和具体内容确认。

原生任务共享组织与项目权限、素材用途和模型处理许可、取消与晚结果保护、资料版本复查以及模型用量记录。产物位于私有 `STORAGE_ROOT/<团队>/<项目>/skill_outputs/<任务>/`，下载复查项目权限、源素材授权和文件摘要。媒体费用的实际单位回执与文字token分别保存，单位未知时不捏造费用。

`.env.example` 提供项目图片、视频、音乐、语音及本地识别/去背景模型配置。对应模型、权重或平台资格尚未配置时，页面会说明当前缺项。FFmpeg、Pillow、文档渲染与公开订阅等确定性执行无需另外启动内容服务。第三方算法的许可证与修改说明保存在原生模块的许可证目录；容器与源码包包含本项目执行代码和平台适配器。

文字可配置 `NATIVE_TEXT_BACKEND=mlx` 使用固定来源、版本与校验和的本机 Qwen，或配置 `NATIVE_TEXT_BACKEND=resident_ppu` 使用既有远程 PPU 0 号卡的 Qwen3-VL-32B 文字服务。驻留运行时要求完整64层解码器与 LM head 驻留，使用固定别名 `housignal-qwen3-vl-32b-text`；身份指纹覆盖本地配置、tokenizer 内容和 safetensor 头部、文件大小及修改时间，不代表完整权重内容校验和或已确认的上游版本。

PPU 文字接口经项目专用 SSH 隧道固定连接 `http://127.0.0.1:18891/v1`，认证文件固定为项目所有者持有的 `.runtime/native-qwen.auth`，权限必须为 `0600`，不进入源码包。两种原生文字后端都按单并发运行，只接受纯文字请求；不支持的多模态或工具请求会明确失败，不回退收费云模型。使用既有算力没有证明 DSW 基础费用为零；模型许可证保存在第三方许可证目录。

视频可用项目专用 SSH 隧道直连既有 LightX2V / MiniMax H3 原生推理接口，任务先检查队列、只提交一次并完整校验实际视频和音轨。公开研究的供应商搜索与原生文字推理分开，未获额度时不调用计费搜索。

原生文字的 MLX 与 PPU 用量共同计入 `NATIVE_LOCAL_TEXT_DAILY_TOKEN_BUDGET`，当前共享每日100万token上限；云模型按独立预算和实际用量记录，当前开发配置 `DEVELOPMENT_TOKEN_BUDGET` 为每日20万token。原 Agent 的流式对话继续走独立云模型入口，需要对应凭据、额度和计费授权。

营销稿只取相关核验资料与句式偏好，账号风格或未来计划不作为实拍证据；明确的本次受众和内容要求优先于内部运营资料。拒绝稿的触发句与计数只存私有质检目录，不混入可下载交付物。

`scripts/skill_acceptance/run_live.py` 在明确标记的验收项目中逐项调用真实 API 和持久 worker，下载并核对产物摘要、格式与音画解码。合成输入只证明相应处理路径，不冒充真实房源、平台发布或运营指标。每个任务的产物按任务 ID 独立保存；失败、取消及多次质量重生成的实际调用用量仍逐笔记账，原始单位回执保存在私有目录。文字事实、正文长度、小说附录与原稿变换有生成后门禁，拒绝的草稿不作为交付结果。

逐方法验收见 `reports/skill-acceptance/all-methods-acceptance.json`，实际任务见各 `*-live.json`，语义复审见 `semantic-review.json`。目录准备状态、单测通过、受控样例成功和全部商业验收分别记录；真实账号、发布内容确认及尚未配置的图片、音乐、声音复刻服务仍是完整交付的前置条件。

## 住宅爆款候选检索修正

2026年10月13日补上真正的关键词检索，原“平台热榜信号”已移除；“筛选已保存线索”仅用于本地记录过滤。搜索可选平台、7/30/90/365天或不限时间、最新/互动/相关排序及点赞播放门槛；用户可仅查看互动已核对的作品。

B站使用固定公开搜索接口与作品详情，不读用户Cookie、不登录、不调用文字模型。公共搜索最多20件、详情核对最多12件；搜索返回的AV路径与BV作品标识按同一作品核对，使用有效BV标识生成规范作品链接，避免因返回链接采用AV格式而丢弃真实候选。指定发布时间范围时，先按最新发布时间取得20件候选，再在本地核对日期、筛选住宅相关性并按用户所选方式排序；结果只覆盖本次有限候选，不代表平台全量热门榜。平台风控或限流会返回受阻状态，不自动重复请求。小红书的网页来源由百炼原生联网搜索返回，仅使用供应商search_info来源字段；不存在来源时不会采用模型正文当搜索结果。缺少日期的候选独立展示，不能算入最近时间窗口；缺少指标不能认定爆款。已核验高互动只代表满足用户选定的累计指标门槛。

能力目录与本地代码接入不等于每项都完成真实运行验收。具体文字、媒体、账号和发布能力仍需核对所需模型、素材、账号权限与平台返回回执，不能用目录数量证明全部可用。

匿名B站来源尚未通过稳定性门槛：同请求已观测到200返回20作品与412风控两种结果，GUI后台查询也出现受阻；2026年10月14日修复后已取得真实候选，具体记录见下方真实搜索验收边界。来源阻断会如实保留blocked状态，不能将静态样本、模型正文或网页索引未知指标补成爆款。取得部分候选不证明平台级爆款搜索已稳定，也不代表全部Easel能力可用。

发现页支持本项目运营账号与独立研究账号两种抖音来源。新建方向默认使用本项目运营账号，与账号页使用同一项目会话；已有登录可直接「核对已有登录」，不会因为独立研究账号未连接而要求重扫。账号状态与核对分别读取既有`platform-accounts/douyin/status`和`platform-accounts/douyin/verify`接口。只有显式选择独立研究账号时，才显示独立研究连接区：研究登录只打开抖音公共官网，独立保存到本项目 `douyin/research/profiles/DouyinResearchProfile`，不复制运营账号或全局Easel的会话。二维码通过项目授权接口读取，安全验证由本人在官方窗口完成；等待阶段支持结束连接。公开搜索只读取当前关键词首屏中的作品链接、发布时间、作者与公开互动字段，缺失指标保留空值。返回作品按所选条件排序，不声称已取得平台热门全量排序或近期增速。

## 房地产内容目录与参考视频拆解（2026年10月14日）

内容工作台的「发现」提供「内容灵感／我的参考」。内容灵感直接展示后台已整理的专业、流量、信任、获客、转化五类作品；当前类别显示核心作用和对应选题，共19个选题方向。切换类别与选题仅筛选已载入目录，不发动在线搜索。前端移除关键词、地区、平台、门槛、已保存研究方向、搜索记录和账号连接表单。选中题目后的「按此选题策划」可带入标题、角度、内容目的与提纲，计划仍沿用现有项目选题方向与事实校验。

`GET /api/projects/{pid}/operations/research/catalog`只读当前租户项目的持久来源快照，规范作品链接并去重，保留实际采集时间、原始来源、已观察指标和未知值。后台通过`scripts/refresh_content_catalog.py`明确指定组织、项目、用户后，将19个选题作为五个有界搜索任务交给现有Worker；重复运行复用同类别活动任务。平台搜索沿用既有登录与公开来源规则，受阻不会补造视频或互动数据。既有研究方向和任务记录继续保存在后台，前端浏览不调用这些搜索入口。

2026年10月15日修正目录时间语义：作品采集时间与互动采样时间分别显示；作品缺少自身日期时保持待补充，不借用类别更新时间。重新导入公开索引时，平台来源的原采集时间、指标和`metrics_observed_at`保持原值，索引整理时间另存为`index_collected_at`；纯网页索引条目可更新自身收录时间，但未知互动量仍为待观察。相关回归与实际目录页面验证位于`reports/daily-content-research-20261015/`，不代表本轮重新完成了平台搜索或爆款召回验收。

后台也支持`--index-file`导入已经核对的公开作品索引，记录官方作品链接、标题、作者、发布日期、采集日期、类别与选题，来源标为「公开网页索引」，未取得的平台互动量保持空值。导入的目录行使用`catalog_only`与个人收藏区分；用户明确点击「收藏并研究」后加入「我的参考」，并保留原始证据、研究笔记和分析结果。已取得真实平台快照的作品通过任务身份收藏，纯索引不冒充平台API数据。原片可打开研究、关联授权视频并继续拆解与策划。

目录卡片支持16:9视频封面和点击播放。后台`scripts/enrich_content_catalog_media.py`从对应B站作品的公开API或同身份官方网页获取真实封面，只接受已核对图片CDN；先结束网络阶段再锁行合并，默认只处理缺少有效封面的作品。目录GET只读取封面记录。封面为空或加载失败时显示中性占位，保留播放入口。点击B站作品打开官方站外播放器弹窗，播放器地址由规范原作链接与一致的BV标识构建（`p=1&autoplay=1&muted=0&poster=1`），iframe明确授予autoplay权限，且只在用户点击封面后挂载；进入目录时不预载或自动播放视频。不信任传入的任意播放器URL；关闭弹窗卸载iframe。其他平台及无法内嵌时提供已校验原作入口。视频播放由原平台提供，不下载视频到项目素材库。

「已观测增量」比较同一项目近30天、最近100次成功搜索中同一作品、同来源的可比较采样，间隔至少5分钟。显示真实采样区间、指标差值与该区间的平均点赞速率，不外推24小时热度；缺值、计数回落、缺少基线或不兼容旧口径分别保留未知与待复测。累计高互动与近期增速分开标记，缺少日期的作品不能计入指定近期窗口。排序仅作用于本次实际取得的候选。

搜索结果按任务、平台和作品标识保存到独立参考库，指标快照由服务端从真实搜索记录读取；手动登记链接不补造互动数据。参考可标为待筛选、重点参考或已归档，保存标签、研究重点与复盘结论，以及口播、画面笔记、目标时长和项目方向。研究草稿可以先保存、关闭后恢复，不必同时创建计划。参考与计划采用可重复使用的关联，同一来源可多次形成不同的原创改编；已有计划与脚本提供直接打开入口。

原片链接仅用于保留来源，不自动下载任意平台视频。使用者可关联本项目已确认用途且单独允许AI处理的视频，或上传有使用依据、明确允许处理的参考原片。研究上传最大100MB、10分钟，标记为研究专用素材。视频分析通过持久Worker执行：本地带时间戳ASR就绪时识别实际音轨，FFmpeg按实际解码时间提取不超过8个采样瞬间，再将采样帧与受限转写线索交给当前配置的百炼视觉模型。缺少本地转写能力、音轨或可识别语音时保留口播缺项，可只保存画面证据，不补写口播。

分析保存原片文件摘要、授权修订、实际时间码、转写、可回看的采样帧、表达线索与证据引用。帧观察只对应采样时刻，采样间的动作、镜头和节奏仍未知；模型观察、ASR文字与人工笔记均需复核，不能宣称系统观看了完整视频、证明了爆款成因或取得了实际留存效果。分析结果与编辑区分开，使用者明确导入后才成为可编辑笔记；已有笔记需要确认替换，分析完成不会直接覆盖人工编辑。

核对笔记后进入「视频拆解与脚本改编」，预览当前项目15–60秒的分镜草稿，编辑标题、策划角度、简报和渠道，再保存为计划。仅使用当前有效的已核验项目事实；缺资料时明确待补齐。原片价格、面积、承诺与其他描述保留为来源记录，不能移植为当前项目事实；正式生成的参考上下文仅投影闭集表达结构、受限时间信息与来源摘要，原始参考口播不直接作为项目资料传入。参考原片只用于研究，即使允许AI分析也禁止进入营销成片。计划生成脚本后，通过可视分镜逐行选择本项目授权实拍、字幕、时长、素材起点与顺序，保存新版本，继续既有成片、人工审核与发布流程；失效授权和不可用素材需要先修正。

参考详情的「改编效果与复盘」读取实际关联计划、内容系列及历史版本的发布回执，显示具体发布稿版本、平台状态和回执核验状态。D7／D30分别显示播放、点赞、咨询与资格客户，未观察值保留待观察，实际0保留0；未核实与已下线记录单独标明。关联范围最多为最近100个计划和200条发布记录；同系列可能关联多个计划，不推断唯一归属。「有核实上线回执」不等于当前稿已上线。这些关联不证明参考结构与效果的因果关系，不计算虚构爆款率，不自动从未核验指标学习；团队可前往效果分析回填观察，再人工完善研究结论。

搜索与分析任务可显示进度并在刷新后恢复，取消复用队列权限：创建者或有权限的管理员可取消，观察者不能取消他人任务。参考编辑按预期修订号拒绝并发覆盖；分析任务绑定来源、素材摘要与授权版本，执行和结果提交时复查权限及证据，取消、撤权、租约失效或修订变化后的晚结果不能覆盖新记录。分析和计划写入使用UUID幂等；不确定的网络重试复用请求编号，明确完成、失败或取消后的重新分析使用新编号，同一参考的另一次改编使用新的计划编号。

## 示例项目连续生产流程修正（2026年10月15日）

内容工作台的失败重试现会重新提交同一计划／内容版本，恢复后台任务时读取服务端安全请求白名单；新提交清理旧错误与旧任务状态，成功后打开实际返回的新版本。审核绑定当前预览成片 ID；示例素材显示为测试示意。

策划与脚本生成共用项目来源素材与 `material_basis`，默认不拿历史成片和封面当新来源。示意模式采用统一声明「画面仅作空间示意，不代表实际房源。」；原策划在模型上下文按素材依据投影，事实、授权和原记录保留。来源措辞异常最多一次受限修正，镜头、数值、引用、素材等保持冻结；时间异常仍有一次受限修正。合法否定并列的来源词不会误报，随后肯定陈述继续被拦截。来源异常的字段与脱敏短句保存在私有诊断目录，不公开原始供应数据。

手动修订后的渲染、审核也重验示意来源规则。计划编辑或重新生成后，参考复盘通过成功生成任务的不可变计划归属保留历史发布系列，仍遵守项目／租户隔离、100 计划／200 回执限制；历史参考快照不足的边界保持说明。

审核后，内容工作台可直接准备指定平台的 ZIP（成片、封面、标题、正文、清单），离线准备无需先登录平台。任务恢复与下载绑定同一内容和审核版本。准备结果保持 `dry_run`／`not_published`；平台回执、D7／D30 仍来自实际登记与核对。

## 章节脚本与长片制作（2026年10月15日）

策划默认提供5／8／10分钟选项。长片先生成6至10章总纲，再逐章展开30至80个镜头；手工编辑最多120镜。正文直接来自按顺序连接的逐镜口播，章节保留策划Hook／大纲／CTA及参考结构片段映射。长参考完整分析保留在原记录，模型上下文按相邻结构组压缩并保留全部原片段与证据ID，不只截开头；无原片依据的表达结构明确标为假设。

每章经过来源事实复核、数值单位与事实版本检查、镜头密度和重复句检查才保存私密恢复记录。仅漏引已有核验数量时可精确补引用，未知数字和失效／异项目引用仍拒绝。图片素材起点统一为0，实际成片时间来自配音后的独立时间线。失败重试复用同输入摘要的已完成章节；更新事实、授权、账号、参考或编导方法后重新生成。界面读取服务端章节／镜头进度，长片任务等待窗口为45分钟；服务维护先全局检查运行队列。

编辑器同时呈现章节目的、逐镜口播、画面说明、素材缺口与来源对应。待拍镜头可以先保存草稿，制作前须绑定有效授权素材。示例教学图卡由本地代码绘制，明确标示虚构资料与示意用途；它们不会成为下一条内容默认选用的来源池。真实项目仍需实际资料和授权拍摄素材。

长片使用普通中文配音，按实际音频与供应返回时间边界生成字幕、章节和镜头时间。真实口播和视频均须达到300至600秒，与计划偏差不得超过20%；口播不足明确失败。视频保存独立音轨、逐镜文字与音频摘要，并完整解码检查。审核与离线发布准备继续绑定当前脚本、事实、素材、音轨和最终成片，未审核与未发布保持真实状态。
