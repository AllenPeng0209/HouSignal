# 楼响正式 Web 工作区

React + TypeScript + Vite 前端，继承现有 HTML Demo 的视觉与楼管家入口。业务记录、会话、权限和任务状态全部通过 FastAPI 获取；浏览器只保存当前项目选择，不保存客户、内容或模型密钥。

## 本地运行

后端 API 在 `127.0.0.1:8017` 启动后：

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5177/`。Vite 将 `/api` 代理到后端，会话使用同源 HttpOnly Cookie。开发模式可点击“填入示例账号”；不会自动登录，生产构建隐藏该入口。

```bash
npm run check
npm test
npm run build
```

生产产物在 `dist/`，同源反向代理 `/api` 到后端。前端没有模型密钥配置项，不使用 `VITE_*` 传入秘密。

## 页面与交互

- 楼管家：真实百炼会话任务、历史对话、资料与客户引用、停止任务、失败重试、切换项目隔离对话。
- 工作台：实际项目概况、咨询待办、内容进展。背景图明确为 AI 空间示意。
- 楼盘资料：版本化事实编辑、有效期、人工核验与过期。
- 素材库：真实文件上传、传输进度、私有文件预览、用途授权、独立 AI 处理授权、识别草稿与文本。
- 内容工作台：参考视频／内容类别／想法进入策划台，Skills 生成三种方向，采纳为计划再写脚本；保留排期、新版本编辑、实际 MP4 渲染、人工审核、导出与发布回执。
- 咨询与客户：咨询录入、联系授权、四项资格确认、分配、临时查看授权联系方式、跟进和阶段、撤回授权。
- 效果复盘：D7 / D30 指标，未观察保持空值，销售记录与人工采纳建议。
- 组织设置：真实成员角色、项目范围、停用、团队名称、模型配置状态、退出登录。

关键页面权限由真实 `/api/auth/me` 响应决定；服务器仍是最终权限校验。事实与脚本尚未保存时不能进入核验／成片审批。模型文本用 React 文本节点与受限 Markdown 样式渲染，没有 HTML 注入。
