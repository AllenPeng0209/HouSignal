# 楼响内容方法与生产 SOP

版本 v0.1，2026年10月11日。适用于首个豪宅销售团队试点，配合[产品 PRD](02_产品PRD.md)使用。下面的流程与模板是拟议操作标准，尚未通过真实客户试点验证。

## 1 编辑目标

每条内容解决一个真实的居住判断问题。具体事实和镜头负责说明房子是什么，顾问判断负责解释它对某类需求意味着什么，销售负责回应观众主动提出的后续问题。AI 整理和提出表达方案，行业人员对事实与判断负责。

一个可用结构是“问题 → 现场证据 → 生活解释 → 适配与取舍 → 合规下一步”。这个方法由公开研究及本项目目标归纳，不是小艾大叔本人教程或授权模板。[内容研究与来源](01_小艾大叔内容研究与产品启发.md)

## 2 开工资料清单

| 资料 | 提供人 | 首轮最低内容 | 缺失处理 |
| --- | --- | --- | --- |
| 营销许可与主体 | 业务负责人 | 可推广房源、渠道、主体、期限和证明 | 只能整理内部草稿 |
| 房源基础资料 | 事实负责人 | 具体房源、面积口径、用途、图纸、交付状态及来源 | 缺哪项就不表达哪项 |
| 动态信息 | 销售负责人 | 当前报价口径、状态、预约条件、有效期 | 对外价格和状态相关主张阻塞 |
| 真实素材 | 拍摄或运营 | 原片、拍摄日期、空间标签、许可、可剪辑范围 | 输出补拍清单 |
| 顾问判断 | 行业负责人 | 关键使用需求、适配条件、已知限制 | AI 只提问，不自动编专业结论 |
| 客户问题 | 销售 | 去标识的问题和回答依据 | 首期可用团队常见问题，标明来源 |
| 账号和入口 | 渠道负责人 | 账号权属、发布方式、入口权限和实际展示位置 | 默认人工站内承接，不能自建违规导流 |
| 品牌表达 | 负责人 | 客户授权样稿或表达方向、禁用表达 | 使用通用专业表达 |

资料库须区分具体在售房源、样板间、公共配套和示意图。不同时间、楼层、朝向或房况的素材不能混合冒充同一套房。地址公开精度、门牌、业主照片、车牌等由授权和隐私范围决定。

## 3 一次楼盘访谈

建议用45至60分钟录音访谈，由客户确认可转写和模型处理范围。录音形成资料草稿，录音中的说法仍需核验。

1. 这个楼盘当前可以公开推广哪些房源？谁负责批准资料？
2. 客户通常为哪种生活需求来？近期反复问了哪三个问题？
3. 哪个空间设计最值得解释？有没有图纸、尺寸、真实操作或走位镜头？
4. 同一特点对哪些需求有帮助，对哪些需求需要权衡？
5. 哪些信息不能仅凭视频确定，必须看资料或现场验证？
6. 当前报价、可售状态、服务和费用是什么口径，何时再确认？
7. 有哪些营销表达是团队明确禁止使用的？
8. 咨询由谁接？通过哪个已批准入口？多久反馈一次？

访谈输出三类卡片：待核验事实、顾问观点、待补资料。不要把所有句子放进统一“知识库答案”而丢失类型。

## 4 事实卡模板

| 字段 | 填写说明 |
| --- | --- |
| fact_id 与 property_id | 系统生成及所属楼盘 |
| 适用房源 | 楼栋、房源版本或公共范围，内部编码即可 |
| 主张与单位 | 一个事实一张卡，面积须有口径 |
| 来源位置 | 文件、页码、时间码或获准使用的公开链接 |
| 有效期 | 动态事实须设置，过期需重新核验 |
| 公开范围 | 内部、对外、限定渠道等 |
| 状态 | unverified、verified、disputed、expired |
| 核验责任 | 人员、日期、核验依据和版本 |

脚本引用事实必须保留限定条件。例如公共配套“计划建设”不能在改写时变成“已开放”；历史成交不能变成当前售价；样板间不能写成最终交付。来源冲突时请负责人处理，不能取更有卖点的一份。

## 5 选题卡与人工筛选

每轮生成5至10题，首轮只生产一条主内容。建议卡片字段：问题、目标生活需求、为什么现在要讲、支持事实、可用镜头、缺资料、顾问解释、适配边界、咨询目的、负责人和渠道。

人工按四项内部标准评估，每项0至2分：问题是否具体、证据是否齐全、与楼盘是否相关、后续服务是否可兑现。证据缺失的题不能因总分高而进入发布。评分只帮助讨论，不是流量或转化预测。

首轮可选“多人共同生活时，接待动线会影响哪些日常活动”。如果没有真实动线资料，则选题停在待补信息；不生成某楼盘已经实现完全分流的结论。更多原创题型见[研究文档](01_小艾大叔内容研究与产品启发.md)。

## 6 脚本模板

| 段落 | 任务 | 建议画面 | 必须核对 |
| --- | --- | --- | --- |
| 开场 | 提出一个具体判断问题 | 同一实景中的关键细节 | 不制造房价、客流或名额焦虑 |
| 证据 | 说明2至3项能核查的细节 | 实景操作、图纸或可证明的镜头 | 每项事实都绑定当前版本 |
| 解释 | 说明对某种生活需求的意义 | 真人走位、使用演示 | 条件、观点与事实分开 |
| 取舍 | 说明适合条件或需要核实的事项 | 对应真实空间 | 不硬编缺点，不隐瞒重大限制 |
| 结束 | 给出一次能兑现的下一步 | 已批准的入口说明 | 符合账号与平台允许位置 |

60至90秒是首轮主片的建议长度，最后按真人试听或实际音轨测量。配音读不顺时修改表达，不能加速到损害可理解性；内容无需为凑时长重复夸赞。

原创示例句使用占位符，不能直接发布：“如果你经常在家接待朋友，先看[已核验的动线事实]。镜头里[真实可见细节]，这对[具体需求]意味着[顾问判断及条件]。但[已确认取舍或待现场核实项]仍需要留意。想了解这一点，可通过[平台允许的咨询入口]提出你的问题。”

## 7 镜头清单与补拍

一个镜头对应一个解释目的：建立位置、证明细节、展示动作、说明关系或表达真实观点。镜头卡记录空间、机位、实际片段入出点、事实引用、说话内容、可识别私人信息、素材许可和是否需要补拍。

推荐按生活动线采集，具体采用哪些段落由选题决定：到达与进入、接待、厨餐、起居、私密空间、家务与服务、离开。镜头不能据此推断隔音、安全、法定面积或设备性能；需要专业报告时提出资料任务。

补拍清单要说清为什么缺。例如“缺进入餐厨的连续走位，不能证明路线关系”，比“缺高级空镜”更有用。原片缺失或比例不合适时补拍或换版式，不能用生成图补成真实房况。

## 8 视觉与音频审核

编辑检查镜头是否来自同一适用房源，裁切是否改变观众对空间的判断，字幕是否与实际音轨一致，封面数字是否引用当前事实，是否有未经授权的人物、照片、门牌、车牌、商标和音乐。

实景修色、图文版式和字幕可以使用工具协助。房源结构、采光、窗外景观、朝向、装饰和交付状态不得凭空生成。示意图不能混入实景序列而无说明；AI 标识按实际素材与平台要求处理。音轨使用真人录音及合法背景音乐，不能未经授权模仿小艾大叔或其他人的声音。

导出后用实际 MP4 检查完整播放、总时长、声画同步、字幕、封面和移动端裁切。仅看渲染日志不能结束媒体验收。

## 9 渠道发布与回执

发布前复核批准快照中的账号、作品、事实版本、素材许可、标识和入口。主片导出后在平台官方界面人工发布；包装适配也需审核。修改过的平台标题或文案回填实际版本，并重审受影响主张。

发布回执包含作品 URL 或 ID、账号、真实发布时间、对应批准版本和截图或后台记录。平台审核中、拒绝或删除分别记录；下载包不等于成功发布。主链路账号不具备某类入口时暂停该入口，使用已核验允许的路径，不做隐蔽跳转。

## 10 销售承接与每周复盘

销售在平台允许范围回应主动咨询，先解释服务和信息用途。客户愿意进一步沟通时，仅记录必要且获授权的联系标识、需求和来源。不要因观看高价房内容就假设客户财力，也不要默认有手机号就有购房需求。

销售逐条确认资格、下次行动和实际阶段；未获客户说明的预算和时间标为未知。每周用30分钟查看已成熟发布数据、去重咨询、需求确认、预约与真实带看、销售反复解释的问题及内容误解。

复盘输出最多三项优先任务：需要修正的资料、需要补充的镜头、下一条内容问题。资料修改由事实负责人批准；选题由运营批准；涉及联系客户的动作仍由负责销售按授权处理。AI 提议不能直接执行这些动作。

## 11 每条内容的完成标准

- 所有公开事实有来源和有效版本，主观判断明确条件。
- 真实素材和音轨许可适用于本账号、本渠道和当前用途。
- 成片完整播放通过，字幕和视觉不误导。
- 发布包对应批准快照，入口和标识符合已核验要求。
- 发布后有真实作品回执；观察窗口和指标来源可追溯。
- 每个咨询有负责人、授权依据和结果；不知道的来源保留 unknown。
- 复盘形成有证据、有人批准的下一步任务。

内部测试、演示联系人和占位资料必须标为测试，并从业务成果统计中排除。
