# 楼响 HouSignal｜设计对标与视觉规范

研究日期：2026-10-11。对象：豪宅销售团队桌面工作台。依据：楼响产品 PRD 与《信息架构与页面交互》。

本模板是针对楼响任务的设计归纳，表达设计取舍；不代表经过对照实验验证的“行业最佳”。研究使用公开官方产品页、帮助文档和官方图片说明，未登录这些产品的客户工作区。公开页面浏览器读取出现超时，因此不把以下尺寸、颜色或字体称作对标产品的实测值。

## 1. 参考产品与取舍

| 官方参考 | 已查阅的产品事实 | 楼响采用的设计判断 |
|---|---|---|
| [Linear：2026 UI refresh](https://linear.app/changelog/2026-03-12-ui-refresh) | 官方更新强调统一页头、导航和视图控件，并弱化侧栏以突出主内容。 | 统一工作台框架；页头只承载上下文和常用动作。浅灰侧栏与白色内容区形成轻微层级，减少装饰。 |
| [Linear：Display options](https://linear.app/docs/display-options) | 文档支持列表/看板切换、分组、排序和可见属性选择。 | 工作流按状态呈现；核心字段常驻，次要字段进入详情，避免把所有信息塞入卡片。 |
| [Attio：Create and view records](https://attio.com/help/reference/managing-your-data/records/create-and-view-records) | 记录可在表格、看板与记录页查看；右侧预览能保留列表上下文，并展示重点属性、活动和任务。 | 咨询与客户使用紧凑表格；点击行打开右抽屉，销售阶段、下一步和来源记录放在同一处。 |
| [Frame.io：官方产品页](https://frame.io/) | 官方资料介绍素材元数据、面板式空间、评论、审阅、转写和版本相关能力。 | 素材卡保留类型、空间标签与使用状态；审核区采用媒体预览加评论/依据面板，素材版本和审核决定清楚分开。 |
| [Jasper：Brand Voice](https://www.jasper.ai/brand-voice) | 官方资料将品牌声音、语气、风格和视觉指南作为可调整的生成上下文，并展示品牌声音对照预览。 | 创作前选择“专业、克制、生活化”风格；写稿时保留规则和事实依据，生成结果继续可编辑。 |

以上每个来源仅摘取与本设计有关的能力和布局原则。没有复刻对标产品的 Logo、截图、页面、文案或独有视觉资产。

## 2. 统一模板

模板名称：**楼响 · 清晰内容工作台**。

“清晰”体现在三个可回答的问题：这套房有什么可靠依据；当前内容还差哪一步；客户由谁在什么时候跟进。AI 的存在通过任务和结果体现，不需要常驻大型聊天窗口。

### 2.1 框架与尺度

| 项目 | 楼响规格 |
|---|---|
| 主布局 | 固定左侧栏 + 顶部上下文栏 + 可滚动内容区 |
| 左侧栏 | 232 px；分组标签 11 px；导航行高 40 px；图标 18 px |
| 顶栏 | 64 px；左侧面包屑/楼盘，右侧搜索、成员和常用操作 |
| 栅格 | 8 px 基础；局部文字间距允许 4 px |
| 页面边距 | 桌面 32 px；平板 24 px；窄屏 16 px |
| 栏间距 | 24 px；卡片内边距 24 px；紧凑列表 16 px |
| 标题 | 页面 28 px / 1.3；模块 18 px；正文 14 px / 1.6；说明 12 px / 1.6 |
| 圆角 | 普通容器 10 px；按钮/输入 7–8 px；状态标签 5 px |
| 表格 | 表头 40 px；数据行 56–64 px；行点击打开详情 |
| 详情抽屉 | 440–480 px；窄屏全宽；固定底部主操作 |
| 对话框 | 520–640 px；明确标题、正文、关闭和主次按钮 |
| 阴影 | 仅浮层和悬浮可点击卡使用轻阴影，普通内容靠细线分区 |

### 2.2 配色

| Token | 色值 | 用途 |
|---|---|---|
| `canvas` | `#F7F8FA` | 工作区背景 |
| `surface` | `#FFFFFF` | 内容容器与顶部 |
| `sidebar` | `#F5F6F8` | 侧栏 |
| `ink` | `#20242C` | 主要文字 |
| `secondary` | `#68717E` | 解释、日期、次级字段 |
| `muted` | `#939AA5` | 辅助文字，避免用于必要信息 |
| `border` | `#E6E9EE` | 卡片和表格分隔 |
| `primary` | `#345DE3` | 主操作、选中、链接、重点曲线 |
| `primary-soft` | `#EEF2FF` | 选中导航和信息提示底色 |
| `success` | `#23745C` | 已完成/已核验文本，辅以文字与图标 |
| `warning` | `#98691E` | 待补依据、待回执；使用浅底色 |
| `danger` | `#B34F4F` | 失效、争议、阻塞；仅用小范围提示 |

大面积用白、灰和石墨文字。冷蓝只表达行动和选中状态。豪宅气质通过照片、留白与排版形成，不靠金色、荧光、巨型渐变和过多阴影。

### 2.3 字体与图形

- 使用系统无衬线字体：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", "Microsoft YaHei", sans-serif`，本地打开无需字体联网。
- 数字使用等宽数字特性；指标名称必须带观察窗口与口径，未回填用“待回填”。
- 图标使用同一组 18–20 px 细线 SVG；图标承担辨认功能，不单独替代关键按钮文字。
- 品牌采用简单字标与几何线条。避免 emoji、AI 火花图案和满屏动画。
- 真实照片进入楼盘概览、素材库、分镜与封面；普通 CRM 表格和指标区保持清楚。

## 3. 页面与交互模板

| 页面 | 信息模板 | 主操作 |
|---|---|---|
| 工作台 | 一条当前活动 + 关键闭环指标 + 待办/阻塞 + 最近内容；照片集中在活动或楼盘区域 | 继续当前活动 / 创建活动 |
| 楼盘资料 | 概览照片与基本信息；事实簿/素材库切换；列表点击看依据、核验状态和授权 | 补资料 / 人工核验 |
| 内容活动 | 资料 → 选题 → 文案分镜 → 审核交付 → 发布回执 → 数据复盘的连续步骤 | 当前步骤只有一个突出动作 |
| 创作与分镜 | 编辑区、镜头条、证据面板；保持当前内容版本、事实引用和风格可见 | 生成草稿 / 保存修改 / 提交审核 |
| 素材审阅 | 预览为主；旁边放状态、用途、授权和反馈；点击照片打开预览 | 选入当前镜头 / 添加反馈 |
| 发布交付 | 已审版本、交付清单、咨询动作和人工回执；每项状态明确 | 导出交付包 / 录入发布回执 |
| 咨询与客户 | 可筛选咨询表；右抽屉展示来源、销售确认、负责人、下一步和跟进记录 | 确认销售线索 / 保存跟进 |
| 工作台 · 效果分析 | 观察窗口、来源完整度、内容表现、咨询候选与已确认线索分开；反馈到下一选题 | 填数据 / 采用下一轮建议 |
| 团队设置 | 成员与权限、品牌表达、事实规则与渠道能力；模型细节进入次级设置 | 保存设置 |

### 3.1 状态与反馈

- 按钮写动作，如“生成 3 个选题”“提交审核”“录入发布回执”，避免只有“开始”“下一步”的含混表达。
- 点击列表行或卡片提供明确 hover、焦点或“查看详情”提示；选中行保持高亮。
- 抽屉可关闭、可通过 Escape 退出；弹窗有关闭、取消和确认；返回不会清空已填内容。
- 异步模拟使用短进度与结果状态；无需凭空显示模型 token、运行日志或无法解释的成功概率。
- 原型里的保存、生成、审核、导出、回执和客户跟进都应产生可见状态变化；信息缺失时说明具体字段。
- 已核验、待核验、失效、争议必须同时有文字；颜色不是唯一表达。
- 显示“人工发布”和“人工资格确认”；不要用按钮暗示原型已连通平台、真实 AI 或成熟 CRM。

### 3.2 屏幕适配

- 1440 px 桌面保留完整 232 px 导航；内容容器按页面需要使用双栏或表格。
- 1024 px 减少三栏密度，把证据面板改为可展开区域。
- 768 px 以下侧栏变成抽屉导航，页面边距 16 px；表格变成信息卡或局部横向滚动；模态和详情全宽。
- 必要交互目标至少 40 px，高频主按钮建议 44 px；键盘焦点清晰。

## 4. 图片使用与内容真实性

本地图片来自 Pexels，确切来源、许可、下载 URL 与文件尺寸见[素材来源](素材来源.md)。图片仅用作虚构楼盘的 UI 摄影示意；不同照片不得被包装为同一真实房屋的核实证据。

产品页应显式标注“示意楼盘 / 摄影示意素材”。演示面积、价格、姓名、咨询数和发布数据应标为演示数据。照片没有被补窗景、放大空间或替换设施；仅做等比例缩小和 JPEG 压缩。

## 5. 实现检查清单

- 同一框架贯穿工作台、资料、创作、发布、客户和复盘。
- 页面标题、核心解释、主操作在首屏清晰可见。
- 主要流程能完整点击，修改后的状态可在相关页面看到。
- 强调色不超过一个主色；状态色范围克制。
- 楼盘照片不充当验证凭据；模拟结果不伪装成真实接口回执。
- 长标题与中文内容不被不必要截断；表格重要字段不会挤出画布。
- 空态、未回填、阻塞和成功均提供具体动作及反馈。
